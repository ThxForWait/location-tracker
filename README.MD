# Albion Location Tracker

Клиент для Windows, который помогает строить общую карту **Дорог Авалона** в Albion Online.

Дороги Авалона — сеть зон, связанных порталами, которые появляются и исчезают. Трекер пассивно читает сетевой трафик игры, замечает, когда игрок переходит из одной зоны в другую, и отправляет этот переход на сервер карты ([location-tracker-web](https://github.com/ThxForWait/location-tracker-web)). Сервер собирает переходы от многих игроков и показывает живые порталы на общей карте.

## Чего трекер не делает

Трекер — пассивный наблюдатель. Он видит только то, что игра и так передаёт по сети на ваш компьютер, и берёт из этого один факт: **из какой зоны в какую вы перешли**.

- **Не вмешивается в игру:** не меняет файлы и клиент игры, не внедряется в процесс, не читает и не изменяет его память.
- **Ничего не отправляет игре** и не влияет на игровой процесс: никакой автоматизации, ботов или макросов.
- **Не обходит защиту:** не расшифровывает зашифрованный трафик игры.
- **Не даёт преимущества в бою:** не показывает других игроков, мобов, ресурсы, сундуки и их позиции.
- **Не собирает лишнего:** о каждом переходе на сервер уходят только ID двух зон и время. Для входа используется Discord-аккаунт: сайт получает только имя, ID и аватар, без почты и переписки.

## Возможности

- захват трафика со всех сетевых интерфейсов с автоматическим переключением (VPN можно включать посреди игры);
- разбор протокола Photon (Protocol18) и определение перехода между зонами;
- отбор переходов, которые нужны карте: порталы Авалона и постоянные связи открытого мира; города, данжи и хайдауты не отправляются;
- фоновая отправка с повторами, не тормозящая разбор трафика;
- вход через Discord в браузере, у каждого устройства свой токен.

## Запуск

Нужны Windows и [Npcap](https://npcap.com).

```bash
go build -ldflags "-X location-tracker/config.Version=1.0.0" -o tracker.exe .
```

```bash
tracker.exe -debug
```

При первом запуске трекер откроет браузер для входа через Discord. Флаг `-debug` отправляет данные на локальный сервер `http://127.0.0.1:8000`, без флагов — на боевой. Остальные флаги: `tracker.exe -h`.

Тесты: `go vet ./... && go test ./...`

Подробное описание устройства — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
